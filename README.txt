АЛЬФРЕД СКАНЕР 3.0
==================
PWA для iPhone. Исходный код и документы обрабатываются браузером; серверу GitHub Pages передаются запросы только за файлами самого приложения.

НОВОЕ
- Последовательная съёмка нескольких страниц без создания отдельного PDF после каждого снимка; непрерывный режим камеры при поддержке Safari.
- Автоматическое выделение белого листа на контрастном фоне (экспериментальный алгоритм).
- Ручная коррекция четырех углов с увеличительной лупой.
- Группы (папки) документов, перенос, переименование и удаление.
- Добавление страниц в документы, созданные в версии 3, и изменение порядка до сохранения.
- Черновик страниц сохраняется локально в IndexedDB между запусками.
- Экспорт PDF в «Файлы» через меню «Поделиться».

ОГРАНИЧЕНИЯ
- В PWA предусмотрена непрерывная съёмка через доступ камеры браузера (getUserMedia). В зависимости от версии Safari разрешения и возможностей камеры могут отличаться. Если режим недоступен, используется системная камера iPhone (с отдельным нажатием для каждого снимка).
- Автоматическое определение границ работает по светлоте и цвету; на светлом фоне/с бликами требуется корректировка точек.
- Ранее созданные в версии 2 PDF остаются доступны, но добавить страницы к ним нельзя (в версии 2 страницы отдельно не сохранялись).
- Данные IndexedDB могут быть удалены iOS при очистке данных Safari или нехватке места. Всегда делайте копии PDF в «Файлах».
- Шифрование данных на уровне приложения, OCR, поиск по тексту и синхронизация НЕ реализованы.

УСТАНОВКА / ОБНОВЛЕНИЕ С iPHONE
1. Распакуйте ZIP в приложении «Файлы».
2. На github.com/levkuk/-alfred-scanner откройте Add file / Upload files.
3. Загрузите ВСЕ ФАЙЛЫ из этой папки (НЕ сам ZIP) в корень репозитория.
4. Commit directly to the main branch -> Commit changes.
5. После публикации GitHub Pages откройте:
   https://levkuk.github.io/-alfred-scanner/?v=3
6. Если открыт старый экран — закройте вкладку и откройте ссылку снова.
7. Safari: Поделиться -> На экран Домой -> Добавить.

РЕКОМЕНДУЕМАЯ ПРОВЕРКА
1. Сфотографируйте ОДИН тестовый лист на темном столе.
2. Убедитесь, что на миниатюре видно «Авто ✓». Если нет, нажмите на миниатюру и поправьте углы.
3. Нажмите «Снять следующую» и сделайте второй снимок.
4. Переместите страницы через меню «…», сохраните PDF.
5. Создайте группу, переместите документ в группу, экспортируйте PDF в «Файлы».

Если автоопределение ошибается на конкретном фоне, пришлите обезличенную тестовую фотографию, снятую камерой, а не скриншот редактора. Это позволит улучшить пороги и геометрию.
